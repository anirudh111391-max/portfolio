# Portfolio

A single-page, modern portfolio landing page built with HTML, CSS, and JavaScript.

## Project Contents

- `port.html` — the entire portfolio page in one file.
- `.vscode/extensions.json` — recommends the Live Server extension for VS Code preview.

## Languages Used

- HTML
- CSS
- JavaScript

## How to Use

### Option 1: Open directly in VS Code

1. Open this folder in VS Code.
2. Open `port.html`.
3. Right-click in the editor and choose **Open with Live Server** if you have the Live Server extension installed.
4. Or open the file directly in your browser using the file system.

### Option 2: Use Live Server (recommended)

1. Install the **Live Server** extension by Ritwick Dey.
2. Open `port.html` in VS Code.
3. Click **Go Live** in the status bar.

## Requirements

- No build tools required.
- No local dependencies required.
- An internet connection is required because the page loads Tailwind CSS, GSAP, Lucide icons, and Google Fonts from CDN links.

## Will it work in VS Code?

Yes. This is a plain HTML file with embedded CSS and JavaScript, so it works in VS Code.

For the best experience, use the Live Server extension to preview it in a browser.
